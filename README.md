# Volleyball Formation Sandbox

This is a minimal React + TypeScript MVP for a 2D volleyball formation and choreography tool.

## Setup

Run the following commands in the project root:

```bash
npm install
npm run dev
```

The application will start on `http://localhost:5173` (Vite default).

## Features (planned)

- Visualize a top-down volleyball court
- Create and name players
- Drag players and define movement paths
- Animate players along Bézier curves
- Save/load formations

This README will be updated as development progresses.
